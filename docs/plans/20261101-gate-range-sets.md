## Acceptance Criteria
- AC1: `range_sets` в server.yml — список или файл (относительно server.yml; `#`, пустые строки);
  имя по nameRe, непустой, ≤50 000, адреса/CIDR, без /0 и IPv4-в-IPv6.
- AC2: сигнатура `ranges: <набор>`; boks пишет в JSON группы `range_sets` с теми наборами, что называют
  её сигнатуры (маскированные CIDR); группа без ссылок — байты прежние; ссылка на отсутствующий набор и
  `range_sets` в самой группе — отказ при разборе.
- AC3: гейт (образ gate10): адрес в наборе + заголовки → совпадение (403/бан в enforce); вне набора —
  нет; IPv6; неизвестный/пустой набор и плохая запись — отказ провижна.
- AC4: ревизия держит набор: rollback на ревизию 1 возвращает её список в конфиг гейта.
- AC5: формат не поднимается (маркер — гейта, 8): любой boks передаёт группу как записана; старый образ
  отказывает громко (strict decode Caddy).
- AC6: мутации — выключенная проверка адреса и выключенное развёртывание — роняют тесты.
