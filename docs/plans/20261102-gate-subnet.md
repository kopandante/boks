## Acceptance Criteria
- AC1: токен проходит с другого адреса своей /24 (IPv4) и /64 (IPv6); с другой /24 и /64 — 403 `ip_mismatch`.
- AC2: IPv4-mapped IPv6 — как IPv4; разные семейства не совпадают; не-адрес не совпадает ни с чем.
- AC3: `page_first` помнит IPv4 по /24 (одна запись на /24), IPv6 — по /64 как раньше; `static_rhythm` — по
  точному IPv4, как раньше.
- AC4: `gate_token_ip` = `exact|net|google|no` у каждого `/api/`-запроса, чей токен прошёл подпись и срок и
  несёт адрес (и на отказах после чтения токена); адрес токена в журнал не пишется.
- AC5: продление на API (`token_ttl`) принимает токен своей сети, новый токен — на точный адрес запроса;
  страница по-прежнему выдаёт токен точному адресу при любом другом адресе токена.
- AC6: векторы сайта: v4-mapped и upper case IPv6 — класс `net`, прокси по ним как по токену точного адреса.
- AC7: мутации ключевых условий роняют тесты.
